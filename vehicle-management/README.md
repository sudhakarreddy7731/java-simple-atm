# Vehicle Management System

Demonstrates OOP concepts including:
- **Inheritance**: All vehicles extend the abstract Vehicle class
- **Polymorphism**: Each vehicle type implements startEngine() differently
- **Abstract Classes**: Vehicle is an abstract base class with abstract methods

## Vehicles Included
- Car
- Bike
- Bus
- Truck
- ElectricCar

## How to Run
```bash
javac vehicle-management/*.java
java VECHILE_MANAGEMENT.Main
```
