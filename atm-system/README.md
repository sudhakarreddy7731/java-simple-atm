# ATM System

A simple ATM application demonstrating basic banking operations.

## Features
- Check balance
- Deposit money
- Withdraw money
- User-friendly menu interface

## Classes
- **Account**: Manages the user's balance and transactions
- **ATM**: Provides the user interface and operations
- **Main**: Entry point for the application

## How to Run
```bash
javac atm-system/ATM/*.java
java ATM.Main
```

Enter initial balance when prompted and use the menu to perform operations.
