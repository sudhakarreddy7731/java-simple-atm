# Java Learning Projects

A collection of Java projects demonstrating core OOP concepts and practical applications.

## Projects Included

### 1. ATM System (`atm-system/`)
A simple ATM application showcasing:
- Object-oriented design
- User input handling
- Basic banking operations (deposit, withdraw, check balance)

**Run**: `java ATM.Main`

### 2. Vehicle Management System (`vehicle-management/`)
Demonstrates advanced OOP concepts:
- **Inheritance**: Extending abstract base classes
- **Polymorphism**: Method overriding with different implementations
- **Abstract Classes**: Creating abstract vehicle templates

**Run**: `java VECHILE_MANAGEMENT.Main`

## Learning Objectives
- Understanding class design and encapsulation
- Practicing inheritance and polymorphism
- Working with user input and control flow
- Building complete applications with multiple classes

## Compilation
Compile all Java files:
```bash
javac atm-system/ATM/*.java
javac vehicle-management/*.java
```

## Requirements
- Java 8 or higher
